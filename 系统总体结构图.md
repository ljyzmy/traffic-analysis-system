# 基于YOLOv12的交通流量监控和信号灯管理系统结构图

## 系统总体架构图

```mermaid
graph TD
    subgraph "系统整体架构"
        Client[客户端] --> |HTTP/WebSocket| Frontend[前端应用]
        Frontend --> |API调用| Backend[Java后端服务]
        Frontend --> |直接API调用| PythonAPI[Python模型API]
        Backend --> |内部服务调用| PythonAPI
        Backend --> |数据存储/读取| Database[(数据库)]
        PythonAPI --> |加载模型| Model[YOLOv12模型]
        PythonAPI --> |数据存储| FileStorage[(文件存储)]
        Backend --> |文件访问| FileStorage
    end
```

## 数据流图

```mermaid
graph LR
    subgraph "系统数据流"
        VideoInput[视频输入] --> |上传| Storage[(存储系统)]
        Storage --> |读取| ModelProcessing[模型处理]
        ModelProcessing --> |车辆检测| Detection[检测结果]
        Detection --> |统计分析| Analysis[分析结果]
        Analysis --> |存储| Database[(数据库)]
        Analysis --> |生成| TrafficReport[交通报告]
        Analysis --> |优化| SignalTiming[信号灯时序]
        Database --> |查询| WebUI[Web界面]
        TrafficReport --> WebUI
        SignalTiming --> |控制指令| TrafficSignal[交通信号灯]
    end
```
